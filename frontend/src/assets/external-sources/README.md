# External source marks

These assets are stored with the frontend so the source selector does not depend on external image requests.

- `wnacg.png`: the inline header mark on https://www.wnacg.com/ (retrieved 2026-09-29).
- `x.svg`: the white SVG in X's official brand toolkit, https://about.x.com/en/who-we-are/brand-toolkit (retrieved 2026-09-29).
- `asmr-one.png`: the 128px icon from the ASMR One organization's `kikoeru-navigate` repository, https://github.com/asmr-one/kikoeru-navigate/blob/master/public/icons/favicon-128x128.png (retrieved 2026-09-29). The icon path declared by asmr.one currently returns HTML instead of an image.
- `pawchive.png`: the favicon served at https://pawchive.pw/static/favicon.png (retrieved 2026-09-29).
