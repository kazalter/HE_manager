## 实现

- 默认连接现有 `http://192.168.0.101:8011`，支持 HTTP／HTTPS 地址与反代路径前缀。使用 `/auth/status`、`/auth/login`、`/auth/me`、`/auth/logout`，没有修改服务端、数据库或现有 Web／Android／Electron 业务。
- 原生连接页、账号登录／退出、顶部导航、浅色／深色／跟随系统。保留本地播放入口；媒体库与服务端媒体流尚未接入，没有空白功能入口。
- HttpClient 按服务器创建，Bearer 只进入当前请求头，不放到 URL／进程参数／日志，不自动跟随重定向。响应有大小与读取时间上限，错误提示不回显原始认证响应。
- 密码只用于本次登录并立即清空输入框，不保存。令牌由 Windows 当前用户 DPAPI 保护，并使用服务器地址派生的独立文件名及额外熵；换服务器不复用另一服务器的身份。
- 服务器切换取消旧请求，旧请求完成不能覆盖当前 UI。断网不误删已有凭证；恢复登录遇到 401 时清除过期身份并提示重新登录。退出账号先清除本机凭证，再尝试撤销服务器令牌，离线时明确说明服务端注销未确认。
- 正常关闭取消未完成请求、停止解码并释放播放器；保持加密登录信息，重开后通过 `/auth/me` 验证恢复。离开本地播放页停止解码，再进入仍使用原窗口。

## 验证与证据

核心回归使用独立请求处理器及临时凭证目录，不对生产账号注入错误密码、过期令牌或断网写入：

1. 地址规范化与 API 前缀，拒绝带账号／查询参数的地址。
2. 登录请求的用户名／密码语义、正常退出保留凭证、另一服务器不读取该凭证。
3. 401 清除过期身份，令牌只在 Authorization 头，不进入 URL。
4. 切换服务器取消旧登录，取消后不写入凭证或显示旧身份；旧会话迟到的 401 不删除新会话保存的凭证。

6. Windows 真正的当前用户 DPAPI 加解密、磁盘无明文令牌、复制到另一服务器的密文不可解锁、退出删除凭证。
