## 0.1.1 regression checks — 2026-10-17

13 desktop tests and 6 focused frontend image/viewer tests passed; Vue TypeScript and production desktop UI build passed. Linux Electron Fullscreen API integration test: entered=true, exited=true. On M1 Pro the actual general-image 4× model produced a 512×512 PNG from the synthetic 128×128 fixture in 2121ms (this is an engine availability test, not representative page-size performance).

The previous GUI process predated the final package update and displayed raw AbortError for all image requests with no image workers or cache outputs. It had remained alive after an earlier quit attempt had aborted its shared image queue. The process was fully exited before installing 0.1.1. This release keeps cleanup before quit and adds an exit fallback; cancellation and timeout errors now have actionable messages.

The packaged 0.1.1 Mac arm64 build passed actual Fullscreen API enter/exit and the extended native self-test: Anime4K playback advanced to 2.875s, VideoToolbox-copy, zero dropped frames in the short test, anime 2× and general 4× image output plus cache hits. In the user's affected image viewer, the same 1000×1401 JPG completed general 4× enhancement, the UI showed success, and fullscreen both entered (metadata sidebar hidden) and exited correctly. Private source media and screenshots are not committed.
