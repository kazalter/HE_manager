## 阶段实现与收敛重点

### 1. 跨平台原生菜单与系统集成 (CP-06)
- **平台习惯一致性**：
  - macOS 端建立标准应用菜单（About、Services、Hide、Hide Others、Quit）、“编辑”、“视图”（全屏 `Ctrl+Cmd+F`、缩放重置、放大/缩小、开发者工具）、“窗口”（最小化、缩放、前置所有窗口）。
  - Windows 端建立“文件”（退出）、“编辑”、“视图”（全屏 `F11`、缩放控制、开发者工具）、“窗口”（最小化、缩放、关闭）。
- **快捷键系统收敛**：
  - **Esc 层级契约**：严格遵循“优先关闭当前模态弹层 → 退出窗口全屏沉浸模式 → 关闭媒体查看器返回媒体库”，彻底避免在输入框中误触或在非全屏下意外关闭窗口。
  - **F11 全局全屏契约**：在视频播放与漫画阅读器中均支持 F11 切换窗口全屏。
  - **触控板与滚轮缩放**：macOS 触控板捏合手势（`ctrlKey` + `wheel`）与 Ctrl + 滚轮平滑缩放，与移动手势及点击平移解耦。

### 2. 窗口尺寸、Retina/DPI 缩放与多显示器弹性 (CP-06)
- **最小内容区域硬性保障**：主窗口锁定最小有效内容区 `1024×640`，在 Windows 原生标题栏/边框与 macOS 窗口装饰下通过 `syncMinimumContent` 动态补偿。
- **多显示器与热插拔断开保护**：监听 `screen.on('display-removed')` 与 `screen.on('display-metrics-changed')`；当外接显示器断开时，自动探测当前窗口边界，若超出已有视口则立即将窗口安全拉回主显示器工作区，防止窗口迷失在离线显示器。

### 3. 会话互斥与长时播放资源安全 (CP-06)
- **音视频严格互斥**：打开视频自动终止在途音频；打开音频自动终止视频并注销 `IOSurface` / `D3D11` 共享纹理。
- **GPU 超分与视频互斥**：打开视频自动调用 `ImageCache.cancelPending()` 中止在途推理，视频播放期间禁止提交超分，保障视频 60fps / 0 掉帧率。
- **安全关闭与进度刷写**：窗口关闭前触发 `closeFlush` 与渲染进程握手，等待当前在途进度保存后有序释放 mpv core、sharedTexture 和图像缓存。

### 4. 生产分发包与运行资源交付 (CP-07)
- 生成独立离线自包含分发包，内嵌完整 Electron 44.8.0 运行时、双平台编译的 `he_embedded.node` addon、平台专用 mpv 动态链接库与 Real-ESRGAN Vulkan/Metal 原生二进制及着色器。
- 经过 macOS ad-hoc 签名与 Windows PE metadata 注入。
