# 播放器 UI 对齐 · v1.0.1

2026-10-18，在 Gemini 完成的主线 d321d61 上按用户要求优化桌面播放器。源码修改与 Vue 构建在 Linux 完成；Windows 和 macOS 分别运行本机打包程序，Mac 最终签名在本机完成。

## 行为变化

- 控制栏覆盖在视频画面底部，以渐变底色承载按钮；视频区域不再为常驻工具栏预留高度。
- 播放时闲置 2.5 秒隐藏上下控制层和鼠标；移动鼠标恢复。全屏时同时收起信息侧栏和视频摘要。
- 暂停、拖动进度/音量、鼠标停留在控件、键盘操作控件及打开设置时保持显示。隐藏控件不可误点，Tab 可以唤出控制栏。
- 补齐网页版常用入口：停止/单片循环/顺序/随机播放、直接调节音量与静音恢复、滚轮音量、倍速、原始/16:9/4:3 比例、PNG 截图保存。
- 操作错误提示避开底部控制栏，侧栏只显示桌面实际支持的快捷键。
- 保留现有音轨、字幕、Anime4K、上一项/下一项与进度刷写。单击暂停与双击全屏分开处理，双击不再额外触发暂停。
- 播放器聚焦时支持空格/K、F、M、上下方向键调音量及 Home/End；表单、按钮和带修饰键的输入保留原有含义。
- PNG 保存仅放行当前应用窗口生成、64 MiB 内的 PNG blob；外部地址、其他类型和超限下载继续拒绝。

## 验收

- 前端：31 个测试文件、148 项通过；vue-tsc 与生产构建通过。
- 桌面核心：61 项通过；新增画面比例边界与截图下载来源/类型/体积限制检查。
- Windows 与 macOS 均运行 v1.0.1 真正内嵌播放器，使用独立临时身份与 Linux 测试后端的合成视频。
- 两端完成 1024×640 / 1280×800 布局、音量静音恢复、倍速/比例、设置与 Esc、全屏暂停、全屏闲置隐藏、鼠标唤回、同会话自然结束循环、真实 PNG 保存与关闭释放。
- 两端隐藏状态均为上下控制层 opacity=0、控件 inert、cursor=none；关闭后 surfaces/leases/references 均为 0。
- 测试窗口截图会受 Windows 遮挡限流影响，因此诊断场景显式关闭后台限流，保证截图和过渡动画继续执行；产品默认调度不变。
- 两端各 19 个主进程模块与 70 个 UI 文件匹配当前源码/构建；最终 ZIP 与已测试程序逐文件一致（Windows 210 项，Mac 557 项），Mac 签名复核通过。

详细证据：[Windows 场景](player-ui-1.0.1/player-ui-101-result.json)、[Windows 包审计](player-ui-1.0.1/windows-audit.json)、[Mac 场景](player-ui-1.0.1/mac-ui-result.json)、[Mac 包审计](player-ui-1.0.1/mac-audit.json)。截图和实际保存的 PNG 位于同目录。
