# CP-05：阅读与超分（三种模式、进度同步与 Real-ESRGAN）验收完成

2026-10-18 完成实施方案 CP-05。客户端版本为 `0.5.0`，Electron 固定为 `44.8.0`（Node API 8）。Windows x64 与 macOS arm64 均完成完整打包。

## 已完成的实现

1. **三种漫画阅读模式与独立图片支持**：
   - **单页模式（Single Page）**：单页居中显示、滚轮切页、键盘快捷键、缩放与自适应屏幕。
   - **双页跨页模式（Double Page）**：双页并列显示、日漫 RTL（从右往左）/LTR（从左往右）方向切换、跨页边界处理。
   - **连续卷轴模式（Webtoon / 条漫）**：垂直连续滚动平滑阅读、阅读视口锚定与翻页同步。
   - **独立图片（image 类型）**：与漫画共享完整阅读器交互，支持缩放、平移、当前列表前后项导航与超分增强。

2. **阅读进度同步与第 0 页状态治理**：
   - 阅读进度由 `VisiblePageChanged` 严格在真实渲染绘制后触发，网络预加载不提前推进进度。
   - 卷轴模式以视口中线或底部边界锚定当前已读页；双页模式以已显示的最大页码作为进度。
   - 针对多页漫画第 0 页服务端设为未读的问题，在桌面会话层与客户端实现两步兼容修复（先写入 progress 0，紧随校验 view_status 为 viewing），并在服务端增加 `view_status` 显式写入支持。

3. **Real-ESRGAN / ncnn-vulkan 客户端超分与资源管理**：
   - 支持动漫 2×（`realesr-animevideov3`，scale 2）与图片 4×（`realesrgan-x4plus`，scale 4）。
   - 在 Apple Silicon Mac 上通过 Metal/Vulkan 实测运行，32x32 -> 64x64 及 180x180 -> 360x360 / 720x720 超分结果精确无误。
   - **并发限制**：推理并发限制为 1，有界在途队列，tile 固定 256，`1:1:1` 线程配比。
   - **上限与安全**：单张输出像素严格限制在 4000 万像素以内，动态图（acTL）与未知格式安全保留原图。
   - **缓存与淘汰**：基于服务器 + Token + 图片内容指纹 + 模型的持久化缓存键，磁盘缓存自动以 1 GiB 上限进行 LRU 清理淘汰。
   - **音视频互斥**：打开视频播放时，自动调用 `cancelPending()` 中止在途推理，并暂停新超分请求，确保 GPU 渲染及着色器带宽完全留给视频。
