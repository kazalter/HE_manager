# CP-03 进展：会话与写入顺序核心

阶段进行中。CP-02 已提交推送，后续 CI 修正和双平台成功记录见其交付报告。本阶段不标记完成，也不把下述核心服务测试当作打包客户端验收。

已实现 `DesktopSession` 与 `CredentialStore`，尚未接入 `main.cjs`、preload 和 Vue：当前已发布客户端仍沿用原有登录流程。会话核心把 token 作为不透明私有字段，页面快照仅有账号与会话代次；支持登录、首次管理员初始化、服务状态、服务器切换、有效会话恢复和尽力服务端退出。断网恢复不会删除已加密凭据，也不接纳未重新验证的缓存账号；401 才使当前身份失效，416 保持身份。普通读取随旧身份中止，迟到响应不能修改新身份。

同一服务器＋媒体 ID 的 PATCH 使用保留于身份切换后的同一串行队列。旧在途请求保留旧服务器与 token；旧未发送请求在出队时丢弃，新账号请求等待旧在途请求结束。请求超时后服务端提交状态仍不可确认，沿用方案中对跨设备状态覆盖的限制。普通进度合并、节流、漫画第 0 页的两步逻辑写入尚待完整集成。

凭据存储以注入的 Electron `safeStorage` 加密能力为边界，原子写入服务器绑定密文，磁盘保存／清理串行执行；无加密能力时不落盘明文。单元测试使用独立测试 cipher，不能代替 Windows DPAPI／Mac Keychain 的实际主进程验证。

验证：桌面全部 34 项通过，其中新增 9 项覆盖迟到 401、并发登录、切换服务器、跨账号同媒体写入、离线恢复与退出、密文文件和保存／退出顺序。独立 Windows 合成 FastAPI 经已有 SSH 转发完成 [8 项真实服务检查](CP-03/CP-03-session-contract.json)：无凭据快照、60 项分页请求与总数、实际打开详情、只改收藏字段、鉴权 Range 206、416 保持登录、本地退出及服务端撤销。该运行使用 Node v26.9.0，无 Electron 窗口；不代表已完成客户端分页或系统凭据集成。
