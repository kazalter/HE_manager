## 当前实现

`DesktopSession`、`CredentialStore` 已接入主进程、preload 和 Vue。桌面登录／首次管理员初始化／退出通过窄化 IPC；页面只取得账号、会话代次和状态，token 保留在主进程，不解析 JWT 或构造 refresh 接口。he 协议代理及 libmpv 单独使用 Bearer，资源 URL 仅携带非凭据会话代次。桌面启动清除旧 renderer token；Web 继续使用原有登录机制。

旧读取随身份失效取消，迟到响应不能改新身份；主进程通知驱动旧界面和常驻音频清理。播放器打开需要当前身份已验证的作品详情，图片增强结果与缓存 URL 在返回和读取时再次检查代次。切换身份会停止旧播放器和图片任务、清除缓存显示授权。

主媒体库采用桌面每页 60 项、offset 与 X-Total-Count；继续观看明确查询 viewing＋opened。列表与详情读取支持取消和迟到结果淘汰，卡片实际打开前验证详情，并显示加载／失败反馈；列表、封面和悬停不调用有副作用的详情接口。漫画页和缩略图显式 track_progress=false，主进程代理也强制该参数。

同一服务器＋媒体 ID 的 PATCH 与实际打开 GET 共用跨身份保留的串行队列。未发送的连续普通进度仅在同一身份和阅读场景内合并；元数据与打开请求形成屏障，每个等待方得到独立响应体。多页漫画第 0 页的 progress=0 和 viewing 修正在同一队列操作内执行，第二步仅在仍为最新意图时进行有限重试；单页保留 viewed。旧在途请求保留旧服务器与 token；旧未发送请求在出队时丢弃，新账号请求等待旧在途请求结束。媒体进度回调固定打开时的身份和场景头；原生视频事件携带旧资源地址，在暂停、切换与关闭时捕获最终位置。元数据响应只应用本次请求字段，进度确认只更新尚未被新位置取代的状态。网络超时后服务端是否已经提交仍不可确认，保留方案关于跨设备最后写入覆盖的限制。

凭据以 Electron 44 的异步 safeStorage API 保存为服务器绑定密文，原子替换，保存／清理串行执行；没有加密能力时不写明文。新配置没有凭据文件时不访问钥匙串。登录恢复在后台进行，窗口先显示可恢复的检查状态，避免系统凭据调用阻塞整个主进程。当前 v0.3.0 仍是开发中版本；加密记录 v2 尚未对旧开发版 v1 做迁移。

创作者、推荐及连续切换通过共享查看器包装层，在挂载桌面阅读／播放组件前验证真实详情；主页已有验证时复用结果，普通 DTO 更新不会重新打开作品。四个常驻业务 store（去重、漫画下载、ASMR 下载、X 导入）按身份创建独立闭包，旧请求、存储写入和轮询不复用新身份；桌面任务键按服务器＋账号隔离，重启时可恢复同一账号任务，不接管原有无归属键。Web 保留现有单例和任务键。
