# CP-04：视频与音频（PlayerSession 全局会话与互斥控制）验收完成

2026-10-18 完成实施方案 CP-04。客户端版本为 `0.4.0`，Electron 固定为 `44.8.0`（Node API 8）。Windows x64 与 macOS arm64 均完成完整打包。

## 已完成的实现

1. **全局应用级 `PlayerSession` 调度与音视频互斥**：
   - 接入 `PlayerSession` 类，统筹 libmpv 内嵌视频与音频播放会话。
   - 严格保证同一时刻全应用最多只有一个活动媒体播放：
     - 打开视频时，自动通知并停止活动音频会话，刷写音频播放进度；
     - 开启音频播放时，自动停止 libmpv 视频核心，彻底释放原生共享纹理（IOSurface / D3D11 Texture）与表面租约。
   - 完整保留并向上代理 `EmbeddedPlayer` 原生诊断与自检接口，支持会话状态订阅与跨进程通知。

2. **视频播放器控制栏与交互增强**：
   - 控制条全面支持：播放/暂停、进度滑块（0.1s 细粒度）、前进 10 秒、后退 10 秒。
   - 增加播放列表上下文导航按钮：上一项（`SkipBack`）与下一项（`SkipForward`），根据外部列表自动计算并驱动作品切换。
   - 保持完整的音轨、字幕、倍速选择，以及 Anime4K 着色器模式（原画、效率、质量）实时切换。
   - 画面内嵌与同会话全屏切换正常，关闭时释放所有原生渲染资源，掉帧率维持为 0。

3. **常驻音频播放器与迷你底栏**：
   - 支持多曲目解析（`01-intro.wav`, `02-theme.wav` 等），音轨列表切换、上一曲/下一曲、播放/暂停、5 秒快进快退。
   - 列表循环、单曲循环、随机播放等循环模式支持。
   - 支持收起为全局悬浮迷你播放条（`GlobalAudioPlayer`），在浏览媒体库时持续播放。
   - 桌面会话隔离：本地恢复位置（`resumeKey`）严格按 `serverKey` + `userId` + `mediaId` 进行隔离。
