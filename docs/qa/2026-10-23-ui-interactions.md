## 已修复的核心问题

下表同时记录已有缺陷和本轮交叉复核纠正的中间回归。其中“401 后一直检查登录”和“双指结束误翻页”由本轮初次修改引入，最终集成已修正，未当作原仓库缺陷计数。

| 优先级 | 触发与影响 | 最终行为 / 验证 |
| --- | --- | --- |
| P1 | 漫画旧进度写入排队时切到另一作品，队列执行使用当时的当前作品 ID | 显式传捕获的 mediaId；deferred 旧写阻塞、切换作品、释放队列验证只写原作品 |
| P2 | Web 初始化短暂断网、超时或 503，把仍有效的 Token 清掉 | 保留凭据但不放行未验证用户，显示连接错误，重试后恢复 |
| P2 | 旧请求的 401/用户响应或旧退出操作晚到，覆盖新登录 | 请求凭据与初始化代次保护；真实 Axios adapter 经过正式拦截器验证 |
| P2 | 当前 /auth/me 401 被拦截器清 Token 后，初始化提前返回，永久停在“正在检查登录状态” | 当前初始化在 finally 结束 ready 状态；实际 401 请求链回归通过 |
| P2 | 清除筛选时本地 ref 监听器又把旧 favorite 条件写回 URL | 单次更新 URL，由路由统一恢复筛选；真实 HomeView 清除全部筛选且保留 view |
| P2 | 分页本地取数和路由监听同时取数 | 只由路由触发新页请求；实际点击下一页验证 /media 仅请求一次 |
| P2 | HTTP 局域网环境无 clipboard API，或权限拒绝，复制无反馈/假成功 | 兼容 fallback，仅浏览器确认成功才显示成功；失败提示手动复制、清理 textarea 并恢复焦点 |
| P2 | 手机条漫到底仍未报告末页，放大后缩放栏不可操作；音频拖动仅 pointerup 时锁在 scrubbing | 末页/缩放恢复控件及 pointerup seek 行为测试通过；安全区样式需真机抽样 |
| P2 | 双指缩回 1 倍后抬指被当作翻页，或剩余一指不能继续平移 | 分开记录整次多指序列与当前触点；三种结束方式不误翻页，下次单指正常翻页 |
| P2 | 桌面播放器焦点/快捷键反馈不一致；长按播放、全屏键反复切换 | 捕获阶段只对首次按键切换，输入/按钮不劫持；箭头连续 seek 保留，控制栏及时显示 |
| P2 | 设置离开后继续轮询，目录移除失败只写控制台 | 清理轮询/提示定时器、卸载后不再更新，目录输入去空格，移除失败给可读提示 |
| P3 | 缺少桌面下载入口、未知 hash 空白、空分页/越界摘要与无后缀卡片异常 | 下载入口、未知路由回首页、范围约束、扩展名/数值边界防护 |

其他保留修正：创作者查看器关闭用 replace，避免新增重复历史项；带时区的丢弃时间不重复拼 Z；推荐请求被替换/页面卸载时取消。

### iOS 的已修复问题

- 创作者详情卡片的星标原来绑定空回调；现在使用正式收藏逻辑并显示失败。
- 按媒体串行提交收藏，旧响应不覆盖最终意图，失败恢复最近确认值；刷新保留待提交意图。
- 创作者分类与媒体库刷新有请求代次，旧请求不覆盖新分类/新数据。
- 已有数据刷新失败保留内容并给重试入口；创作者列表/详情区分失败与正常空结果。
- 错误密码返回 401 仅作为登录错误，认证请求 401 才广播会话过期。
- 返回媒体库后刷新进度/收藏；作者入口打开的作品若不在当前筛选序列中，使用当前单作品序列。
- 搜索提示与实际可搜的标题、标签、来源一致。

这些由正式工程编译和真实 localhost 网络/ViewModel 回归验证；SwiftUI 点击和播放器保存完成时序仍需设备确认。

## 复核后撤下的改动

- 音频播放器直接调用 history.pushState/back、随路由/卸载后退的方案，避免破坏 Vue Router 历史。
- 手机同栏目点击同时主动回根与 RouterLink 导航的重复链，避免丢分类/筛选。
- 仅凭 history.state.back 存在就返回上一页的查看器关闭逻辑，避免深链关闭回错页。
- 用作者名代替作品标题搜索的伪作者入口，以及把未知分辨率当较低画质的比较修改。
- 无实际 UI 调用证据的公共 store Proxy 扩展、无调用的分页 prop、与任务无关的新下载清理行为。
- 在测试内复制正式函数再断言的镜像测试；改为挂载实际组件、正式 Axios 拦截器和真实网络/ViewModel 代码。
